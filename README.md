## 👨‍💻 About Me

I'm **Musab Khurram**, a Full-Stack Developer and Founder of **Synchro9**, a web, mobile and custom ERP development company based in Karachi, Pakistan.

I build production-ready web applications, SaaS platforms, ERP systems, dashboards, AI-powered applications and mobile experiences.

I work across both frontend and backend, from designing responsive interfaces to building APIs, databases, authentication systems, third-party integrations and deployment.

### 🚀 What I Work With

* **Frontend:** React, Next.js, TypeScript, JavaScript, Tailwind CSS, shadcn/ui
* **Backend:** Node.js, Express.js, REST APIs
* **Databases:** PostgreSQL, Supabase, MySQL, MongoDB
* **AI:** OpenAI APIs, Claude APIs, AI integrations, function calling and AI-powered workflows
* **Payments:** Stripe and payment integrations
* **CMS:** WordPress, Webflow, Sanity
* **Cloud & Deployment:** Vercel, Netlify, Azure
* **Other:** Git, GitHub, Docker, Redis, Twilio, Playwright, Vitest

### 🛠️ What I've Built

I've worked on a range of projects including:

* Custom **ERP systems** for warehouse operations
* **SaaS platforms** and business management systems
* Inventory, billing and financial reporting systems
* CRM and internal business tools
* AI-powered assistants and automation workflows
* E-commerce websites and Stripe payment systems
* Logistics dashboards and data visualization
* Mobile-first web applications
* WordPress websites and custom integrations
* REST APIs and backend calculation engines
* Authentication, roles, permissions and audit systems
* Performance optimization and database integrations

One of my major projects was a **custom warehouse ERP**, covering inventory and stock tracking, GD/BL and packing lists, InBond/ExBond operations, gate passes, NOCs, client accounts, billing, financial reports, user permissions and operational reporting.

I've also built AI applications using **OpenAI APIs, function calling, Twilio SMS/voice and Node.js**, along with modern SaaS applications using **Next.js, TypeScript, PostgreSQL and Supabase**.
